# 🔍 React Search App

A simple search application built with **React class components**. It connects to an external API to fetch and display search results, supports local storage, loading indicators, and error handling.

---

## 🚀 Tech Stack

- React (Class Components)
- TypeScript
- Tailwind CSS
- Vite

---

## 🧠 Features

- 🔍 **Search input connected to an API**
- 💾 **Persists search term in Local Storage**
- 📄 **Displays results with name and description**
- ⏳ **Shows loading indicator while fetching**
- ❌ **Handles API errors with messages**
- 🧱 **Error boundary with fallback UI and test button**
